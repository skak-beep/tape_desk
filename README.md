# テープ机 (tape_desk)

テープ片を机に並べて鳴らす、lo-fi 音コラージュの試作。
1ファイル (`index.html`) で完結。iPhone Safari / Chrome / Edge で動く。

## 動かす
- ローカル: `python -m http.server 8000` → http://localhost:8000
- 公開: GitHub Pages (main ブランチ / root)。HTTPS 配下ならマイク録音が使える。

## 構成
- 机 (A): テープ片 = パンチカードの列。裏返し / 速さ (±3oct) / 濃さ / 奥行き
- グリッド (Medusa 風 8x8): 横=音程 (スケール固定)、縦=音色の層。長押しで焼き付け → シーケンス → 1周をテープに
- 質感: カセット / ダスト / 水の中 / 隣の部屋 / 壊れたラジオ / 宇宙 / ガラス / きれい
- 空間: めちゃリバーブ / エコー / きらめき (1oct 上の影をホールへ)
- 書き出し: 15 / 30 / 60 秒 (MediaRecorder)
